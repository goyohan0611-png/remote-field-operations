# GitHub 공개 전 점검표

이 폴더는 공개 후보입니다. 파일 검사가 회사의 자료 공개 검토를 대신하지 않습니다.

## 공개 범위 확인

- [ ] 소속 조직의 포트폴리오·기술 사례 공개 기준을 확인했습니다.
- [ ] 기존 UI·서버·에이전트 선별 소스의 공개 범위를 확인했습니다.
- [ ] 본인 프로토타입과 타인의 구현·제품 기여를 구분했습니다.
- [ ] 문서에 적힌 본인 경험과 사실 관계를 확인했습니다.

## 민감정보 확인

- [ ] 실제 회사·고객·현장 이름과 로고가 없습니다.
- [ ] 실제 IP·도메인·이메일·계정·장비 식별자가 없습니다.
- [ ] 비밀키·토큰·인증서·비밀번호·설정 파일·DB·로그가 없습니다.
- [ ] 설치 파일·제조사 SDK·DLL·운영 설정·원본 Git 이력이 없습니다.
- [ ] SOURCE-MAP.json에 적힌 UI·핵심 구현만 포함했고 공개 권한을 확인했습니다.
- [ ] 이미지 속 글자·탭·주소창·파일명에도 식별정보가 없습니다.
- [ ] 생성 이미지가 아닌 실제 브라우저 캡처임과 가상 데이터임을 구분했습니다.

## 업로드 방식

1. 기존 회사 저장소를 공개로 전환하거나 복제해 올리지 않습니다.
2. 이 공개 후보 폴더만 대상으로 새 저장소를 준비합니다.
3. 처음에는 비공개로 업로드하고 파일 목록과 커밋 내용을 검토하는 방식을 고려합니다.
4. 공개 가능 범위 확인과 최종 검토가 끝난 뒤 공개 여부를 결정합니다.
5. GitHub Pages를 사용한다면 `npm run build` 결과인 `dist/`만 정적 배포합니다. 데모 서버는 외부에 배포하지 않습니다.

`.gitignore`는 이미 포함된 비밀정보나 이전 커밋을 지우지 않습니다. 이 폴더 외의 운영 저장소·개발 이력을 함께 업로드하지 마세요.

## 데모 안내

- 가상 현장과 상태의 개수는 시연 데이터이지 설치 실적이 아닙니다.
- 기존 UI의 검색·필터·장비 상세·모니터링 탭·녹화 이력·가상 파일 목록을 사용할 수 있습니다.
- 기본 모드는 외부 통신이 없습니다. 선택적 통합 모드만 루프백 데모 서버와 통신합니다.
- 운영 접속·실제 인증·키 발급·파일 삭제는 동작하지 않습니다. implementation의 원본 핵심 코드는 데모 시작 시 실행하지 않습니다.
- 기본 상태 데이터는 합성 예시이며 실시간 운영 데이터가 아닙니다.
