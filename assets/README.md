# 공개 이미지의 출처

- `overview.png`: 기존 UI를 가상 데이터로 실행한 현장 목록 화면의 브라우저 캡처.
- `device-detail.png`: 같은 데모의 장비 상세 화면.
- `monitoring.png`: 같은 데모의 모니터링 탭. 실장비 영상은 연결하지 않음.
- `recordings.png`: 가상 녹화·전송 이력 화면.
- `architecture.svg`: 공개 설명을 위해 새로 작성한 개념 구조도 원본.
- `architecture.png`: 위 SVG를 브라우저에서 렌더링한 이미지.

기존 제품의 UI 코드와 스타일을 분리해 사용했고 회사명·로고·운영 데이터는 교체했습니다. 회사·고객의 실제 자료와 외부 사진·로고·제조사 이미지·생성형 이미지는 사용하지 않았습니다. 폰트는 시스템 UI 글꼴을 사용합니다.
